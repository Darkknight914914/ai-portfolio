# Escalation of data-quality issues (fictional example policy)

## Blocking issues
If a report has any blocking issue it must not be sent. The report owner fixes the source data and runs the checks again. Blocking issues are raised to the Operations Lead on the same working day.

## Warnings
A report with warnings only may be sent if the report owner records each warning and its reason in the control log.

## What a review must contain
A review states the file checked, the number of rows, each failed control with its violation count and example row numbers, whether the report can be sent, and who has to act.
